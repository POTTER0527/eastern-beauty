# Eastern Beauty

Modern Oriental Beauty & Wellness 品牌形象網站第一版。

暫定品牌名稱為 **Eastern Beauty**（東方美容）。名稱與標誌集中在 `src/lib/brand.ts` 與 `src/components/brand/Logo.tsx`，方便未來替換。

## 技術

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## 本地開發

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000)。

## 頁面

- `/` Home
- `/about` About
- `/beauty-library` Beauty Library
- `/beauty-library/[slug]` 文章內頁
- `/eastern-beauty` Eastern Beauty
- `/seasonal-wellness` Seasonal Wellness
- `/contact` Contact

電子報與聯絡表單為靜態 UI，尚未串接後端服務。
